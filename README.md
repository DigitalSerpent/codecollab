# Code Collab 

Веб-платформа для совместного редактирования кода в реальном времени с возможностью изолированного запуска программ в браузере.

## стек

* **Backend:** C# / ASP.NET Core (Razor Pages)
* **Real-time микросервис:** Python (FastAPI) + WebSockets — вынесен в отдельный сервис для изоляции real-time трафика и экономии ресурсов сервера.
* **База данных:** SQLite + Entity Framework Core (Fluent API для жесткой настройки связей).
* **Безопасность:** Выполнение кода пользователей изолировано внутри Docker-контейнеров с жесткими лимитами по RAM/CPU. POST-запросы защищены от CSRF (антифорджери-токены).
* **Инфраструктура & DevOps:** Развернуто на VPS (Debian), веб-сервер Nginx (Reverse-Proxy), процессы управляются через systemd, SSL от Let's Encrypt.

## функционал

* **Интерактивный редактор:** На базе Monaco Editor (движок VS Code) с подсветкой синтаксиса, вкладками для файлов и автосохранением.
* **Синхронизация в реальном времени:** Совместная работа в комнатах, отображение курсоров и действий участников через WebSockets.
* **Изолированный терминал:** Запуск скриптов на Python, JavaScript и Bash в безопасном окружении.
* **Кастомизация:** Система авторизации (BCrypt), личные профили, загрузка аватаров и кастомный конструктор SVG-курсоров.

## трудности (Матчасть)

В процессе создания MVP столкнулась со следующими техническими вызовами, которые были успешно решены:
1. **Теневые свойства в EF Core:** Возникала ошибка `SQLiteException: no such column: r0.RoomId1`. Проблема решена явным указанием внешних ключей через Fluent API в `OnModelCreating` и атрибуты `[Column("RoomId")]`.
2. **Оптимизация WebSocket под Nginx:** При деплое на VPS ловила ошибку `502 Bad Gateway`. Исправлено корректной настройкой заголовков `Upgrade` и `Connection` в конфигурационном файле Nginx для проксирования путей `/ws/`.
3. **Ограничение ресурсов хостинга:** Сервер имеет всего 380 MB RAM. Для стабильной работы .NET-приложения был настроен swap-раздел и полностью отключена компиляция кода на стороне сервера.

## применение
Проект ориентирован на использование в образовательном процессе (групповое обучение, менторство), проведение быстрых технических собеседований и код-ревью без необходимости разворачивать тяжелые локальные IDE.
